# intervan-scripts

Intervan scripts is a CLI tool that makes working in the Intervan web-app far more confortable.

## Technologies

For DOM interaction it uses the Playwright package, this allows the user to not have to manually work on the page as much, and it makes some repetitive, time consuming tasks faster and more confortable.

## Usage

Here is a simple step by step to get started:
```
# Go into the project's folder:

cd intervan-scripts

# Always start with:

pnpm start

# You can run for help and to see more options:

pnpm start --help
```
